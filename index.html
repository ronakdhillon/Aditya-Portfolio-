True Metric (e-Māpan 2.0)

Making legal metrology verification digital, transparent, and accessible. True Metric replaces paper-based weighing instrument verification with a full-stack web portal and an offline-first mobile system using GPS-evidenced inspections and QR-verifiable statutory certificates.

What I Built
    Built Next.js 15 & TypeScript portal for trader registration & public QR verification. Designed Supabase database schema & Row-Level Security (RLS) policies. Built Express API generating statutory Schedule IX PDF certificates with QR codes.
A Challenge I Solved

When the database said nothing: A database insert was silently failing due to RLS restricting unauthenticated users. I resolved it by introducing a scoped anonymous insert policy and surfacing error states directly in the UI.
